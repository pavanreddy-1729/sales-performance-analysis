# Sales Performance Analysis

This project analyzes sales data using SQL, Python, and Power BI to identify revenue trends and business insights.

Python
SQL
Power BI
Pandas
Matplotlib

## Key Insights
Top selling products
Revenue by region
Monthly sales trends
Customer purchasing patterns
